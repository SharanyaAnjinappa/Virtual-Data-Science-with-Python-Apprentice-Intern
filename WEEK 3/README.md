
# Week 3 – Statistical Analysis and Hypothesis Testing in Python

## 📌 Overview

This project is part of the **Virtual Data Science with Python Apprentice Internship**.

Week 3 focuses on statistical analysis and hypothesis testing using Python. The Titanic passenger dataset was used to investigate whether passenger gender had a statistically significant association with survival.

The analysis builds upon the data cleaning and exploratory analysis completed in Week 1 and the advanced visualization work completed in Week 2.

## 🎯 Objective

The main objective of this task was to statistically determine whether passenger gender and survival status were associated.

### Research Question

> Does passenger gender have a statistically significant relationship with survival on the Titanic?

## 🧪 Hypotheses

### Null Hypothesis (H₀)

There is no significant association between passenger gender and survival.

### Alternative Hypothesis (H₁)

There is a significant association between passenger gender and survival.
